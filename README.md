# Cookie_Clicker
This is a very simplified version of a cookie clicker. This was my first time using the pygame library so it was really more to figure out the basics of how to use it.

What's Cookie CLicker?: 
- you click the cookie -> you get a cookie
- the more cookies you have, the more you can upgrade the big cookie. this in turn makes it drop more cookies when clicked.

How to run it:
- you need the pygame library installed
